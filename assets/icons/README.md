# Profile heading icons

All icons are stored locally, sized to 24 × 24, and use an explicit blue color so they remain visible on both light and dark GitHub backgrounds. Empty `alt` attributes avoid repeating the adjacent heading text.

- `gnome.svg` and `nixos.svg`: [Simple Icons](https://github.com/simple-icons/simple-icons), [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). The NixOS snowflake represents the platform used by NixBerry; it is not a separate NixBerry logo. Original paths are preserved; color and dimensions are set locally.
- `languages.svg`, `terminal.svg`, `hard-drive-download.svg`, `code-xml.svg`, and `piano.svg`: [Lucide](https://github.com/lucide-icons/lucide/tree/main/icons), recolored locally. See [LICENSE.lucide](LICENSE.lucide) for the ISC notice and the Feather MIT notice covering `terminal.svg`.
